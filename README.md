# MarutamaWorks VPM List

marutama が配布している Unity のツールを、VCC（VRChat Creator Companion）や ALCOM から入れるための一覧です。

## 追加のしかた

- 一覧のページ（https://marutamaworks.github.io/vpm-list/ ）の「Add to VCC」を押す
- 手で追加する場合は、VCC・ALCOM の設定にある「リポジトリの追加」に次の URL を入れる
  `https://marutamaworks.github.io/vpm-list/index.json`

試験中（alpha・beta）の版は、設定の「Show Pre-Release Packages」をオンにしたときだけ表示されます。
